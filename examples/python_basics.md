Python 基础学习材料（本项目原创演示）

Python 的列表是有序且可变的序列，列表元素可以通过从零开始的索引访问。
元组也是有序序列，但元组创建后不能直接增加、删除或替换其中的元素。
字典通过键来查找对应的值，字典中的键必须是可哈希的对象。
集合用于保存不重复的元素，适合对数据进行去重。
函数使用 def 关键字定义，return 语句可以把结果返回给调用者。
for 循环可以依次访问可迭代对象中的元素。
range(3) 依次产生整数 0、1、2，不包含右端点 3。
if 语句根据条件表达式的真假选择执行的分支。
try 和 except 语句用于捕获和处理运行时异常。
with 语句管理上下文，打开文件时可以帮助在退出代码块后关闭文件。
