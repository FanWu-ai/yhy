# 系统操作与演示手册

本章按“知题”页面的导航顺序说明操作。先完成 [安装](02-install-and-run.md)，使用 `API_MODE=demo` 启动。演示只使用本项目原创 Python 资料和固定的 10 道基础题，不联网调用模型，不支持为任意自定义资料自动出题。

## 1 十分钟跑通一轮

### 第一步 载入示例

1. 打开主页的“学习概览”。
2. 点击“体验示例课程”。
3. 系统载入“Python 基础 · 原创演示资料”和 10 道固定题。
4. 去“学习资料”查看正文，内容包括列表、元组、字典、集合、函数和循环等。

重复点击会按精确去重规则复用资料和题目，不是每次生成 10 道新题。示例名称和来源标签会表明它是演示数据。

### 第二步 体验出题流程

1. 打开“智能出题”。
2. 在“学习资料”选择刚才的原创示例。
3. 将数量设为 3，“出题方式”选“本地演示”。
4. 难度固定为“基础”。演示不模拟中等或困难题。
5. 点击“生成练习题”，查看结果提示。

这里返回固定题集的前三题。因为载入示例时已经建立 10 题，总题量可能仍是 10，属于正常精确去重。不能把这些题说成模型刚刚创造的内容。

### 第三步 有意答错一题

1. 点击“开始这组练习”。
2. 对第一题“关于 Python 列表，下面哪一项正确”，正确选项是 A“有序且可变”。为了验证错题流程，故意选择 B。
3. 第二题关于元组选择 B，第三题关于字典查找选择 C。
4. 点击“提交答案”。
5. 预期为 2/3 正确，系统百分制显示约 66.7 分，并显示各题解析与原文引文。

这是可复现的演示验收预期，不是真实模型实验结果。若你选择的题目顺序不同，以题干与实际选项为准，不机械套用字母。

### 第四步 查看并复习错题

1. 打开“错题复习”，默认显示“待复习”。
2. 找到列表题，查看错误次数、上次选择、答案解析和来源。
3. 点击“练习未掌握错题”，这次对列表题选择 A。
4. 提交后，列表题会被标记为已掌握，可以在“已掌握”筛选中看到。
5. 也可以手动“标记已掌握”或“标为待复习”。手动状态是个人记录，不证明真的掌握。

再次答错同一题会增加累计错次并恢复待复习。已掌握不会删除题目，也不会清空历史。

### 第五步 查看记录并备份

1. 打开“练习记录”，应看到刚才两次已提交练习。
2. 打开详情核对得分、作答和解析。
3. 回到“学习概览”，核对已完成练习数和累计正确率。
4. 到“我的题库”点击“导出备份”，保存 JSON。

如果数据库原本为空，且严格完成上面 3 题错 1 题、再复习 1 题答对的流程，累计作答为 4 条，其中 3 条正确，累计正确率为 75%。它不是 `(66.7% + 100%)/2`。已有其他记录时数值会不同。

## 2 导入自己的学习资料

在“学习资料”填写标题、课程，选择“粘贴文本”或“上传文件”。课程不填时界面使用“未分类”。保存后打开资料详情核对正文，尤其关注 PDF 中的表格、公式和文字顺序。

限制：

- 文本正文需要 20–30,000 字符，标题最多 120 字符，课程最多 80 字符。
- TXT/Markdown 用 UTF-8 编码；Markdown 按正文数据处理，不会执行其中的脚本。
- 文件最大 5 MiB；PDF 最多 40 页且必须有可提取文字层。
- 不支持扫描件 OCR、图片、Word 文档和加密 PDF。
- 仅导入资料不会调用模型；演示模式也不会为这份自定义资料自动生成题目。

可以先用下列原创材料验证粘贴保存，再决定是否进行真实 API 实验：

```text
学习记录的基本方法
复习计划应记录学习主题、完成日期和下一次复习安排。
练习时应先独立作答，再查看参考答案和解释。
整理错题时，应保存原题、自己的选择、正确答案和出错原因。
同一题再次答错时，需要重新核查相关知识点，而不能只记答案字母。
资料不足以支持判断时，应补充可靠资料，不应猜测缺失的事实。
```

这段文字用于功能验证，不是经过教育实验验证的理论综述，也不是已经生成好的题库。

## 3 使用真实模型出题

1. 阅读安装指南的真实 API 章节，配置 `.env` 或进程环境变量并重启。
2. 确认侧边栏和“出题方式”显示配置的模型与远程就绪状态。
3. 选择已核对且允许外发的资料，先请求 1–3 道题。
4. 选择“大语言模型”，设置难度，点击“生成练习题”。
5. 浏览器确认框会列出资料标题、全文字符数、接收服务商和模型，并提醒费用。只有你明确确认才会提交远程生成。
6. 若取消，资料仍保存在本机，不发送这次模型请求。
7. 结果返回后逐题核对。引用存在于原文只是程序检查，语义支持、正确答案和干扰项仍由人审核。

当前把所选资料全文发送给服务商，不是仅发送引用句，也没有先做向量检索。不得把需要保密的资料用于试跑。代码交付测试没有使用真实收费 API，不能据此承诺某家账户已可用。

发生错误时界面不会自动无限重试，也不会把失败结果伪装成成功。先核查服务商、权限、模型兼容性和资料长度，再考虑手动重试。每次真实调用可能产生费用，即使输出最终被程序拒绝。

## 4 题库使用

“我的题库”可按资料、难度和关键词筛选。选择要练的题，再点击“开始练习”。每次练习最多 50 题；“在线练习”的快速入口使用已有题库中的前 10 题，不会偷偷调用模型。

题库可以查看答案、解析和来源，以方便自学。这不是防作弊考试系统；不要把“开始练习接口未返回答案”描述成完全无法提前看到答案。

## 5 练习中断和重复提交

- 尚未提交的答案保存在当前页面状态，刷新或离开可能丢失，不具备跨浏览器断点续答功能。
- 点击其他导航或结束练习时，按界面确认决定是否放弃当前作答。
- 不完整作答在前端会受到提示或阻止；后端允许部分答案并把漏答计错，直接 API 调用应留意。
- 同一练习重复提交返回第一次结果，不重复累计错误次数。
- 完成的练习可从历史查看，不必重新提交。

## 6 错题与统计的含义

“待复习”表示本系统记录的未掌握状态。某题答对或手动标记后可进入“已掌握”，它不是客观能力认证。

累计正确率按全部已提交作答记录计算，同一题多次练习会重复进入分母。不同题量练习不做百分比简单平均。知识点统计按题目的文字标签分组，没有复杂知识图谱或能力估计模型。

## 7 导出导入和完整备份

“我的题库 → 导出备份”得到 `quiz-study-export.json`，含资料正文、题目、选项、答案和引文。**不含练习历史、错题状态或生成记录。** 文件包含完整资料，不能随意上传到公共网盘或仓库。

“导入备份”只接受程序支持的 `quiz-study-v1` JSON，最大 5 MiB、100 份资料、500 道题。当前导出也遵守这些上限，过大时会提示改做停机数据库备份。导入是合并和精确去重，不会按备份 ID 覆盖其他资料。页面显示的是处理条数，不一定全部是新记录。

在独立测试数据库验证导入更稳妥。若需要完整保存学习历史，停止服务后备份整个 `data/`，步骤见 [安装与运行](02-install-and-run.md)。不要先删除原数据库来测试恢复。
